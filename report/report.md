# Звіт — Лабораторна: Паралельні алгоритми C++20  
**Варіант 16 — adjacent_difference**

## Мета
Дослідити час виконання для знаходження максимальної абсолютної різниці між сусідніми елементами, порівняти послідовний, політики та власну паралельну реалізацію.

## Методика
Довжини послідовностей: 1000, 10000, 100000, 1000000. Для кожної — 5 різних seed'ів. Усереднення по 3 вимірюваннях. Для власного алгоритму K ∈ {1,2,4,8,16,32}. Запуск у Release (-O3).

## Результати
Результати автоматично зберігаються в `report/results.csv`.

## Аналіз (коротко)
- Для великих N політика `par`/`par_unseq` дає прискорення.
- Власний метод оптимально працює при K ≈ hw_threads.
- Для малих N паралелізація може програвати через накладні витрати.

## Висновок
Паралельні політики та власне розбиття дають суттєве прискорення на великих обсягах даних. Рекомендовано підбирати K відповідно до `hardware_concurrency()`.
